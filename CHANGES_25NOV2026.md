## Optional switches (GitHub → Settings → Secrets and variables → Actions → Variables)
- `NOTIFY_MOVED_BACK=1`: alert when an A+ setup falls back from 1H confirmed.
- `NOTIFY_QUIET=22:30-07:00`: quiet hours for non-urgent alerts.
- `NOTIFY_QUIET_ALLOW`: words that still go through in quiet hours; the default is stop, exit, target, triggered, closed.
